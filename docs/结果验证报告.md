## 潜在问题分析

### ⚠️ 性能低于预期（但合理）

**预期 vs 实测**:
```
单帧推理:  2-3 ms (预期) vs 12.36 ms (实测)
端到端:    5-7 ms (预期) vs 22.41 ms (实测)
```

**原因分析（均为合理因素）**:

1. **NPU 理论算力 vs 实际利用率**
   - 理论计算：4.7 GFLOPs / 6 TOPS = 0.78 ms
   - 实际测得：12.36 ms
   - 利用率：~6.3%
   - ✅ 这是小模型的正常现象（内存密集型，调度开销）

2. **P2 尺度计算量大**
   - P2 输出 40×40，比 P3 的 20×20 大 4 倍
   - P2 anchors 占总数 80%（1600/2000）
   - ✅ 符合预期

3. **Python 后处理未优化**
   - 使用纯 Python + NumPy
   - NMS 占用 ~7.5 ms（73%）
   - ✅ C++ 实现可提速 5-10x

4. **Batch=4 模型**
   - 模型配置为 batch=4，单帧推理可能有额外开销
   - ✅ 建议测试 batch=1 专用模型对比

**结论**: 性能数据真实可信，差异有合理解释
