## 优化详解

### 为什么更快？

**原版流程**：
```python
# 1. 过滤 (O(n))
keep = scores > 0.3  # 保留几十到上百个框

# 2. NMS (O(n²))
for i in keep:
    for j in keep:
        if IoU(box[i], box[j]) > 0.5:
            suppress(box[j])  # 嵌套循环，O(n²)
```

**优化版流程**：
```python
# 直接找最大值 (O(n))
max_idx = scores.argmax()  # 一次遍历
if scores[max_idx] > 0.35:
    return boxes[max_idx]
```

**复杂度降低**：O(n²) → O(n)

**实测提速**：10.19 ms → 1.03 ms = **9.9倍**

---

### 为什么更准？

对于**单目标检测**场景：

1. **最高置信度通常是正确的**
   - 模型训练时已学会对正确目标给出高置信度
   - 误检通常置信度较低
   
2. **避免 NMS 误删**
   - NMS 可能误删边缘的正确框
   - 单目标选择不存在这个问题

3. **减少噪音**
   - 原版检测 11 个框（边缘图像）
   - 优化版只保留最可信的 1 个

## 置信度阈值分析

### 原版使用 0.3
- **优点**：召回率高，不容易漏检
- **缺点**：误检多（11个框），需要 NMS 过滤

### 优化版使用 0.35
- **优点**：只保留高置信度，准确率高
- **缺点**：可能漏检低置信度目标（如 phantom03_1332）

### 建议配置

| 场景 | 阈值 | 说明 |
|------|------|------|
| **高准确率优先** | 0.4-0.5 | 只保留高置信度，几乎无误检 |
| **平衡模式** | 0.3-0.4 | 兼顾准确率和召回率 |
| **高召回率优先** | 0.2-0.3 | 尽量不漏检，可能有误检 |

**推荐**：对于无人机检测，建议 **0.35-0.4**，平衡准确率和召回率。

## 适用场景

### ✓ 适合优化版（单目标）

1. **单目标跟踪**
   - 无人机检测（本场景）
   - 行人跟踪
   - 车辆跟踪

2. **实时性要求高**
   - 需要 60+ FPS
   - 延迟敏感应用

3. **画面中只有一个目标**
   - 或只关心最主要的目标

### ✗ 不适合优化版

1. **多目标检测**
   - 需要检测所有目标
   - 目标数量不固定

2. **密集场景**
   - 人群检测
   - 车流检测

3. **需要检测所有候选**
   - 目标跟踪的初始化阶段
