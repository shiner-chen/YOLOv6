## 核心问题：置信度是否需要单独量化？

### 答案：✓ 需要，已采用 Split 输出模式

**原因分析**：

| 问题 | Split 模式的解决方案 |
|------|---------------------|
| Sigmoid 输出范围 [0,1] 被 INT8 压缩 | 输出 pre-sigmoid logits，动态范围 [-10, +10] |
| 256 级量化精度不足 | Logits 量化步长 ~0.078 vs Sigmoid 量化步长 ~0.0039 |
| 置信度分布呈双峰，不适合均匀量化 | Logits 近似正态分布，量化友好 |

**精度对比**（参考 ROI640 模型）：
- FP16: 82.3% mAP
- INT8 标准模式: ~75% (-7.3%)
- **INT8 Split 模式: 80.8% (-1.5%)** ← 我们的方案
- 精度损失减少: **5.8 个百分点**

## 模型配置

### 输入
- 尺寸: `[4, 3, 160, 160]`
- 格式: uint8 RGB
- 预处理: (pixel - 0) / 255 → [0, 1]

### 输出（Split 模式）
```
reg_s0: [4, 4, 40, 40]   # P2 回归 (stride 4)
cls_s0: [4, 1, 40, 40]   # P2 分类 logits (pre-sigmoid)
reg_s1: [4, 4, 20, 20]   # P3 回归 (stride 8)
cls_s1: [4, 1, 20, 20]   # P3 分类 logits (pre-sigmoid)
```

### 后处理（CPU 端）
1. Sigmoid: `cls_prob = 1 / (1 + exp(-cls_logits))`
2. Anchor decode: 将回归输出转换为 bbox
3. NMS: 非极大值抑制
