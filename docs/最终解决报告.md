# 检测框问题最终解决报告

## 问题历程

### 第1次问题：检测框过大且不准 ❌

**现象**：
- 检测框非常大，覆盖大部分图像
- 位置不准确

**原因**：
- 使用了错误的 decode 方法（假设是中心点+宽高格式）
- 错误地使用 `exp()` 导致宽高爆炸

### 第2次问题：位置对了但框太小 ❌

**现象**：
- 位置基本正确
- 但框太小（28×18像素）

**原因**：
- 使用了正确的 `dist2bbox` 格式
- 但漏掉了关键一步：**distance 需要乘以 stride**

### 最终解决 ✅

**正确的 decode 方法**：
```python
def dist2bbox_corrected(distance, anchor_points, stride):
    # 关键：distance 必须乘以 stride！
    lt = distance[:, :2] * stride  # [left, top]
    rb = distance[:, 2:] * stride  # [right, bottom]
    
    x1y1 = anchor_points - lt  # 左上角
    x2y2 = anchor_points + rb  # 右下角
    
    # 转为中心点+宽高
    cx = (x1y1[:, 0] + x2y2[:, 0]) / 2
    cy = (x1y1[:, 1] + x2y2[:, 1]) / 2
    w = x2y2[:, 0] - x1y1[:, 0]
    h = x2y2[:, 1] - x1y1[:, 1]
    
    return np.stack([cx, cy, w, h], axis=1)
```

## 技术细节对比

### 三种方法对比

以 `phantom03_0830` 为例（stride=4, anchor=[142, 106], distance=[3.31, 2.22, 3.82, 2.28]）：

| 方法 | Distance 处理 | 框尺寸 | 状态 |
|------|--------------|--------|------|
| **错误方法1** | `exp(distance) * stride` | 巨大（数千像素） | ❌ 太大 |
| **错误方法2** | 直接使用 `distance` | 28×18 像素 | ❌ 太小 |
| **正确方法** | `distance * stride` | **114×72 像素** | ✅ 正确 |

### 为什么需要乘以 stride？

YOLOv6 的 distance 输出是**归一化到特征图尺度**的：

```
特征图空间：distance = [3.31, 2.22, 3.82, 2.28]
             这是相对于特征图像素的距离

像素空间：  需要乘以 stride 恢复到原图像素
           distance * 4 = [13.24, 8.88, 15.28, 9.12]
```

**公式**：
```
P2 (stride=4): 特征图 40×40 → 原图 160×160
P3 (stride=8): 特征图 20×20 → 原图 160×160

像素距离 = 特征图距离 × stride
```

## 关键知识点

### YOLOv6 输出格式总结

```python
# 输出不是常见的 (cx, cy, w, h)！
# 而是 distance (ltrb) 格式

reg_output = [left, top, right, bottom]  # 4个值

# 解码步骤：
# 1. 乘以 stride 恢复到像素空间
lt = [left, top] * stride
rb = [right, bottom] * stride

# 2. 从 anchor 点计算边界
x1 = anchor_x - lt[0]
y1 = anchor_y - lt[1]
x2 = anchor_x + rb[0]
y2 = anchor_y + rb[1]

# 3. 转为中心点格式
cx = (x1 + x2) / 2
cy = (y1 + y2) / 2
w = x2 - x1
h = y2 - y1
```

### 为什么容易出错？

1. **不同框架格式不同**
   - YOLO v5/v8: 直接输出 (cx, cy, w, h)
   - **YOLOv6**: 输出 distance (ltrb)
   - 容易混淆

2. **stride 容易被遗忘**
   - Distance 是特征图尺度
   - 必须乘以 stride 恢复到像素尺度

3. **文档不够清晰**
   - 需要深入源码才能发现细节
