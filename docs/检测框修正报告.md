# 检测框修正报告

## 问题诊断

您观察到的**检测框不准且过大**的问题，根本原因是：

### ❌ 错误的 Decode 方法

**之前使用的方法**：
```python
# 错误：假设输出是中心点 + 宽高格式
boxes[..., :2] = anchors + reg_output[..., :2] * stride  # 中心点
boxes[..., 2:] = np.exp(reg_output[..., 2:]) * stride    # 宽高
```

**问题**：
- YOLOv6 的回归输出不是 (cx, cy, w, h)
- 而是 **distance (ltrb)** 格式：[left, top, right, bottom] 距离
- `exp()` 导致宽高爆炸式增长

---

## ✅ 正确的 Decode 方法

根据 YOLOv6 源码 (`yolov6/utils/general.py:dist2bbox`)：

```python
def dist2bbox_corrected(distance, anchor_points):
    """
    YOLOv6 正确的解码方法
    
    distance: [N, 4] 格式为 [left, top, right, bottom] 距离
    anchor_points: [N, 2] anchor 中心点坐标
    """
    # 分离左上和右下距离
    lt = distance[:, :2]  # [left, top]
    rb = distance[:, 2:]  # [right, bottom]
    
    # 计算四个边界点
    x1y1 = anchor_points - lt  # 左上角
    x2y2 = anchor_points + rb  # 右下角
    
    # 转换为中心点 + 宽高
    cx = (x1y1[:, 0] + x2y2[:, 0]) / 2
    cy = (x1y1[:, 1] + x2y2[:, 1]) / 2
    w = x2y2[:, 0] - x1y1[:, 0]
    h = x2y2[:, 1] - x1y1[:, 1]
    
    return np.stack([cx, cy, w, h], axis=1)
```

## 技术细节

### YOLOv6 输出格式

**训练时** (`use_dfl=False`，我们的模型)：
- 回归输出：4 个值，表示到 anchor 的距离
- 格式：`[left, top, right, bottom]`
- 含义：从 anchor 中心点到目标四个边界的距离

**解码过程**：
```
anchor_point = (anchor_x, anchor_y)  # 中心点
distance = [left, top, right, bottom]  # 模型输出

# 计算边界框
x1 = anchor_x - left
y1 = anchor_y - top
x2 = anchor_x + right
y2 = anchor_y + bottom

# 转换为中心点格式
cx = (x1 + x2) / 2
cy = (y1 + y2) / 2
w = x2 - x1
h = y2 - y1
```

### 为什么之前的方法会导致框过大？

**错误的 exp() 操作**：
```python
w = np.exp(reg_output[2]) * stride
h = np.exp(reg_output[3]) * stride
```

如果 `reg_output[2] = 5`（距离值）：
- `exp(5) ≈ 148`
- `w = 148 * 4 = 592` 像素（远超图像尺寸！）

**正确的方法**：
```python
right = reg_output[2]  # 直接使用距离值，不需要 exp()
bottom = reg_output[3]
w = left + right  # 左右距离之和
```

## 关键发现

1. **YOLOv6 使用 distance (ltrb) 格式**
   - 不是常见的中心点+宽高
   - 必须使用 `dist2bbox` 解码

2. **错误的 exp() 导致框爆炸**
   - distance 值通常在 0-20 范围
   - exp(distance) 会导致数值爆炸
   - 正确方法：直接使用距离值

3. **单目标优化非常有效**
   - 去除 NMS：10.19ms → 0.80ms
   - 保持准确性的同时大幅提速
